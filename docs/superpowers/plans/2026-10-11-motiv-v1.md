# Motiv v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construire la PWA Motiv v1 (suivi guitare + sport avec séries, XP, niveaux à défis obligatoires et courbes), hébergée sur GitHub Pages avec Supabase.

**Architecture:** Les règles métier vivent dans `src/domain/` en fonctions pures testées (TDD). `src/data/` charge toutes les données de l'utilisateur en une requête, gère une file hors-ligne et applique les mises à jour de défis. Les écrans (`src/features/`) consomment un contexte `AppData` + `Actions`, ce qui permet de les tester avec des données factices.

**Tech Stack:** Vite 8, React 19, TypeScript, Tailwind CSS 4, React Router 7, TanStack Query 5, `@supabase/supabase-js` 2, `vite-plugin-pwa` 2 (+ `@vite-pwa/assets-generator`), Vitest 5 + Testing Library + jsdom.

**Spec:** `docs/superpowers/specs/2026-10-11-motiv-v1-design.md`

## Global Constraints

- Interface entièrement en français. Textes exacts imposés : « Encore N min de guitare pour tenir la série », « Série tenue aujourd'hui ✓ », « Défi requis », « N log(s) en attente d'envoi », « Exo inconnu », « Temps oublié », « Envie d'y retourner », « Dernière fois : 4×8 à 62,5 kg ».
- Mobile d'abord, largeur de référence 375 px. Navigation basse : Aujourd'hui, Progrès, Réglages.
- Jour = date `YYYY-MM-DD` en `Europe/Paris`, jamais un jour UTC.
- Constantes : objectif guitare 60 min/jour ; sport 3 séances/semaine (lundi → dimanche) ; 1 200 XP/niveau guitare ; 600 XP/niveau sport ; 1 800 XP/niveau global.
- Le site vit sous `/motiv/` (Vite `base`, manifest `scope`/`start_url`, Router `basename`).
- Supabase : projet `gizlmwnknbkexqvfvyrn`. Auth par lien magique, `flowType: 'pkce'`. Ne jamais demander ni stocker le mot de passe de la base.
- Les ids de lignes sont des UUID générés côté client (`crypto.randomUUID()`), pour que les renvois de la file hors-ligne soient des `upsert` sans doublon.
- Travailler sur la branche `v1` ; fusion dans `main` à la tâche 16 (le push sur `main` déclenche le déploiement).
- Chaque message de commit se termine par `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Commandes Node lancées depuis le Bash (Git Bash) de la machine, où `node`/`npm` sont dans le PATH.

## Review Focus

1. **Heure de Paris autour de minuit** : un log à 00 h 30 à Paris (22 h 30 UTC en été) doit tomber sur le nouveau jour. → test dans la tâche 2.
2. **Renvoi d'un log déjà enregistré** (le serveur a reçu mais la réponse s'est perdue) : aucun doublon, la file se vide. → test dans la tâche 9.
3. **Exo du programme supprimé pendant ou après une séance** : l'historique reste lisible, la séance en direct saute l'exo disparu sans planter. → archivage (tâche 8) + test dans la tâche 13.
4. **`exercise_id` absent des JSON** : affiché « Exo inconnu », ignoré par l'XP, les records et les défis. → tests dans les tâches 3 et 5.
5. **Compte neuf sans aucune donnée** : Aujourd'hui affiche série 0, niveau 1 et le défi `scales-1` ; une courbe à 0 ou 1 point ne plante pas. → tests dans les tâches 11 et 14.
